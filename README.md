

# Amazon E-Commerce Website
A responsive Amazon-inspired e-commerce website built using HTML, CSS, and JavaScript. This project demonstrates core frontend development concepts through product browsing, searching, filtering, sorting, and shopping cart functionality.

## Project Overview

This project is a frontend e-commerce application where users can explore products, search for specific items, filter products by category, sort products by price, and manage their shopping cart.

The website is designed to provide a simple and user-friendly shopping experience.

## Features

- Responsive website layout
- Product listing with images
- Product search functionality
- Category-based product filtering
- Price sorting (Low to High and High to Low)
- Add products to cart
- Remove products from cart
- Automatic cart total calculation
- Product quantity tracking
- LocalStorage integration to preserve cart data after page refresh

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactivity
- Font Awesome – Icons
- Unsplash – Product images

4. Run the project using Live Server.

5. Explore the website and test its features.
